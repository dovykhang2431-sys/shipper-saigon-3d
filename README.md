# Shipper Sài Gòn Voxel 3D

Game giao hàng Sài Gòn 3D dạng voxel, chạy trực tiếp trên trình duyệt.

- Lái xe giao hàng qua các con phố Sài Gòn, nhận đơn, giao đúng giờ, tránh xe cộ.
- 5 xe (Xe đạp thồ, Honda Wave, Honda Vision, Ba gác, Tải mini) và 5 nhân vật mở khóa bằng tiền trong game.
- Model 3D `.glb` dạng voxel trong thư mục `models/` (tạo bằng code từ 17 ảnh gốc), tự động tải qua `js/modelLoader.js`. Thiếu file nào thì game dùng model voxel dự phòng có sẵn.
- Chơi tại: https://dovykhang2431-sys.github.io/shipper-saigon-3d/
